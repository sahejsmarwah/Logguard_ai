# Logguard_ai

Logguard_ai is an autonomous incident response AI agent built using LLMs and LangGraph.

It analyzes live logs, deployments, health signals, and code context to identify root causes,
suggest fixes, and generate patch-level recommendations with confidence scoring.

## Features
- Planner–Executor–Validator agent loop
- Tool-based investigation (logs, deployments, health, code)
- Real-time incident triggering via log monitoring
- Live demo UI using Streamlit
